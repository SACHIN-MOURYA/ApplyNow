ApplyNow | Job Portal Website

Welcome to the Job Portal Website! This project is a job portal platform built using the MERN stack (MongoDB, Express.js, React.js, Node.js) where users can register either as a Job Seeker or as an Employer. The platform provides various features that facilitate job searching, job posting, and application management.

Features
1. User Authentication
Login as Job Seeker or Employer: Users can register and log in to the platform as either a Job Seeker or an Employer.
2. Job Search
Search for Jobs: Job Seekers can search for jobs based on different criteria such as keywords, location, and job type.
3. Resume Management
Add Your Resume: Job Seekers can upload their resumes to the platform, making it easier to apply for jobs.
4. Job Creation
Create a Job: Employers can create and post job listings, specifying details such as job title, description, requirements, and salary.
5. Apply for Jobs
Apply for Jobs: Job Seekers can apply to listed jobs with their uploaded resumes.
6. Job Management
Update or Delete Jobs: Employers have the ability to update or delete their job postings.
Technologies Used
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB
